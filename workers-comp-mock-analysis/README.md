# Workers' Compensation Mock Analysis

This folder contains the analysis code and written findings for a mock New York State workers' compensation claims project.

## Files

- `analysis.py` — Colab-oriented pandas analysis for the NYS workers' compensation claims dataset.
- `findings.md` — Summary of observations, trends, and product hypotheses.

## Running the analysis

The analysis expects the NYS claims CSV at `/content/raw_data.csv`. The initial download and `google.colab` display helpers are intended for Google Colab. The data source used by the notebook is the NYS Open Data claims dataset.
